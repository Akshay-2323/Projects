# BFSI SLA & Incident Analytics Dashboard

End-to-end BFSI incident analytics project built using Python, SQL Server, Power BI and DAX.

## Technologies

- Python
- SQL Server
- Power BI
- DAX
- CSV

## Dataset

150,000 synthetic incident records.

## Dashboard

The Power BI solution contains five analytical pages:

1. Executive Dashboard
2. SLA & Performance Analysis
3. Incident & Root Cause Analysis
4. Team & Operational Analysis
5. Ticket & Detailed Analysis
