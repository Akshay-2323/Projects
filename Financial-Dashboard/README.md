# 💰 Contoso Financial Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Financial Analysis Dashboard built using Microsoft Power BI**.

The dashboard provides a consolidated view of financial performance across sales, profit, orders, discounts, products, countries, and business segments.

It is designed to help business users quickly understand financial performance, identify trends, compare markets, and analyze the contribution of different products and customer segments.

---

## 🎯 Project Objective

The objective of this project is to build an interactive financial dashboard that enables users to:

- Monitor overall sales performance
- Track profit and profit margin
- Analyze order volumes
- Understand discount impact
- Compare financial performance across countries
- Analyze profitability by business segment
- Identify top-performing products
- Track sales trends over time
- Compare current performance with the previous year

---

## 📊 Key KPIs

The dashboard includes the following key performance indicators:

| KPI | Description |
|---|---|
| Total Sales | Overall sales generated |
| Total Profit | Overall profit generated |
| Total Orders | Total number of orders |
| Total Discounts | Total discount value |
| Profit Margin | Profitability relative to sales |
| Previous Year Sales | Sales comparison with the previous year |

The dashboard also provides year-over-year comparisons for major financial metrics.

---

## 📈 Dashboard Analysis

### 🌍 Orders by Country

Provides a country-level comparison of order volumes.

This helps identify markets generating higher order activity and compare performance across countries.

### 💰 Profits by Country

Visualizes profit contribution by country using a donut chart.

This allows users to understand how different countries contribute to overall profitability.

### 🏢 Profit Margin by Segment

Analyzes profit contribution across different business segments, including:

- Government
- Small Business
- Channel Partners
- Midmarket
- Enterprise

This provides visibility into segment-level profitability.

### 🏆 Top Products by Sales

Highlights the products generating the highest sales.

This helps identify the major products contributing to overall revenue.

### 📅 Sales by Year

Shows sales performance over time and helps identify changes and trends in sales activity.

### 🏷️ Discount Band Analysis

Provides a breakdown of sales/orders across different discount bands, including:

- High
- Medium
- Low
- None

This helps analyze the distribution of discounts applied across the business.

## 🎛️ Interactive Filters

The dashboard provides interactive filtering capabilities.

### Country Filter

Users can analyze the dashboard for individual countries such as:

- Canada
- France
- USA
- Mexico
- Germany

### Date Filter

Users can select a specific date range to analyze financial performance for a selected period.

All major dashboard visuals respond dynamically to the selected filters.

## 🧩 Data Model

The project uses a structured Power BI data model designed for interactive financial analysis.

The model supports analysis across:

- Date
- Product
- Country
- Segment
- Sales
- Profit
- Discounts
- Orders

A star-schema-based approach was used to organize the analytical data model and support efficient reporting.

---

## 🧮 DAX & Power BI Analytics

The project uses DAX measures to calculate and display important financial KPIs and analytical metrics.

Key analytical calculations include:

- Total Sales
- Total Profit
- Total Orders
- Total Discounts
- Profit Margin
- Previous Year Sales
- Year-over-Year comparisons

These measures allow the dashboard to dynamically respond to filters and provide interactive financial analysis.

---

## 🔄 Data Preparation

Power Query was used as part of the Power BI data preparation process.

The preparation process includes:

- Loading the financial dataset
- Preparing data fields for analysis
- Structuring data for reporting
- Creating relationships between analytical entities
- Preparing the model for DAX calculations
